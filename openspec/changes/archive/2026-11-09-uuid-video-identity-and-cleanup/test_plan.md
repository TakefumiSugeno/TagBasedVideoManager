## 4. 単体テスト：複合条件デシジョンテーブル（C2 / MC/DC 網羅）

### 4.1 対象ロジック 1: 未登録パス動画に対する既存レコード引き継ぎ判定（Phase 2 Relocation Matching）

判定対象: スキャンで見つかった未登録パスのファイル `f` に対して、旧パスが不在（`not (matchedByPath)`）の DB レコード `v` を引き継ぐかどうかの複合条件

- **条件 A**: 旧レコード `v` の正規化パスが今回のスキャンに存在しない（`v` が未マッチプールにある）
- **条件 B**: `v.FileUuid` が設定済みであり、`Some computedUuid` と一致する
- **条件 C**: `v.FileUuid` が `None`（旧DBレコード）かつ `v.FileSize = f.FileSize` かつ（`v.FileName = f.FileName` または `|v.FileModifiedAt - f.FileModifiedAt| <= 2.0s`）

| ケースID | 条件A: 旧パス不在 | 条件B: `FileUuid` 一致 | 条件C: 旧レコードのサイズ＋名前/日時一致 | 期待される判定結果・アクション                                              |
| :------- | :---------------: | :--------------------: | :--------------------------------------: | :-------------------------------------------------------------------------- |
| `DT-01`  |         T         |           T            |                    -                     | **引き継ぎ成立**: 既存 `v.Id` を維持し新パス・新ファイル名で UPDATE         |
| `DT-02`  |         T         |           F            |                    T                     | **旧DB移行引き継ぎ成立**: 既存 `v.Id` を維持し `FileUuid` と新パスで UPDATE |
| `DT-03`  |         T         |           F            |                    F                     | **新規登録**: 既存 `v` は引き継がず、新規 `VideoId` で INSERT               |
| `DT-04`  |         F         |           T            |                    -                     | **新規登録（コピーファイル）**: 元ファイル実在のため別動画として INSERT     |
| `DT-05`  |         F         |           F            |                    T                     | **新規登録**: 元ファイル実在のため別動画として INSERT                       |

### 4.2 対象ロジック 2: 既存・引き継ぎ動画のメディア処理キュー（FFmpeg/ffprobe）投入判定

判定対象: `shouldEnqueue = (durationMissing || thumbMissing) && not isFileNameTooLong`
（ただし `thumbMissing = not (File.Exists(Path.Combine(thumbDir, $"{v.Id}.jpg"))) && not (v.ThumbnailPath |> Option.exists File.Exists)`）

- **条件 A**: `v.Duration = 0L`（再生時間未取得）
- **条件 B**: `Path.Combine(thumbDir, $"{v.Id}.jpg")` が存在する
- **条件 C**: `v.ThumbnailPath` が `Some p` かつ `File.Exists(p)` が真
- **条件 D**: ファイル名 UTF-8 バイト数 `<= 255`（`not isFileNameTooLong`）

| ケースID | 条件A: `Duration = 0` | 条件B: `{thumbDir}/{Id}.jpg` 実在 | 条件C: `v.ThumbnailPath` 実在 | 条件D: `<= 255B` | 期待される判定結果・アクション                                           |
| :------- | :-------------------: | :-------------------------------: | :---------------------------: | :--------------: | :----------------------------------------------------------------------- |
| `DT-06`  |           F           |                 F                 |               T               |        T         | **スキップ**: 完了済みのため `MediaQueue` に投入しない                   |
| `DT-07`  |           F           |                 T                 |               F               |        T         | **スキップ＋パス補正**: `MediaQueue` に投入せず `ThumbnailPath` のみ更新 |
| `DT-08`  |           F           |                 F                 |               F               |        T         | **キュー投入**: サムネイル欠損のため `MediaQueue` に再投入               |
| `DT-09`  |           T           |                 T                 |               T               |        T         | **キュー投入**: `Duration = 0` のため `MediaQueue` に再投入              |
| `DT-10`  |           T           |                 F                 |               F               |        F         | **スキップ（255B超過保護）**: 警告ログのみ記録し `MediaQueue` 投入除外   |

## 6. E2Eテスト・画面検証ケース定義

| ケースID | ジャーニー種別                       | 操作手順（Given → When）                                                                                                 | 期待される画面状態・出力エビデンス（Then）                                                                                      |
| :------- | :----------------------------------- | :----------------------------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------ |
| `E2E-01` | **Happy Path**（移動・リネーム追従） | 動画をスキャン登録してタグ・お気に入りを付与後、ディスク上でファイルを別フォルダへ移動＆リネームして UI の「同期」を実行 | カードが重複せず 1 件のまま新ファイル名・新フォルダタグ付きでお気に入り・既存タグ・サムネイルが維持され PNG 保存されること      |
| `E2E-02` | **Zero-State / 初回起動**            | 動画 0 件の空ディレクトリで Web UI を開く                                                                                | 白画面やエラーにならず、0件案内メッセージが正常表示され PNG 保存されること                                                      |
| `E2E-03` | **Negative / Recovery Path**         | 登録済み動画の物理ファイルを削除 → ①スキャン前にカードをクリックして再生試行 → ②その後「同期」ボタンを実行               | ①画面上に「動画ファイルが見つかりません」の赤色エラートーストが表示され（PNG保存）、②同期実行後に削除済み動画カードが消えること |
| `E2E-04` | **255B超過エラー表示回帰確認**       | 255バイト超過の動画をクリックして再生試行                                                                                | 既存の 422 エラートーストとオーバーレイ表示が壊れず正常に表示されること                                                         |
