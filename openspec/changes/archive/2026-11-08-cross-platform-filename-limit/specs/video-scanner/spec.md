# Spec Delta: video-scanner

## ADDED Requirements

### Requirement: Linux NAME_MAX 超過ファイルの事前検知と警告ログ記録

システムは、動画ディレクトリ同期走査時、スキャン対象となった各動画ファイルについてファイル名単体の UTF-8 バイト数を検査し、Linux カーネルの `NAME_MAX`（255バイト）を超えるファイルを検知した場合、データベースへの動画レコード登録・更新は正常に完了させつつ（SHALL）、データベースの例外エラーログ（`ErrorLogs` テーブル）および標準エラー出力に対して、該当の VideoId、ファイルパス、および UTF-8 バイト数を含む警告ログを記録しなければならない（SHALL）。また、外部メディア処理パイプラインの破綻・無限滞留を防止するため、255 バイトを超えるファイルはメディア処理キュー（`MediaQueue`）への投入から除外（スキップ）しなければならない（SHALL）。

#### Scenario: 255バイト超過ファイルのDB登録と警告ログ出力

- **WHEN** ファイル名単体の UTF-8 バイト数が 270 バイトの動画ファイルを含むディレクトリを同期スキャンした時
- **THEN** 動画はデータベースに正常登録され、かつ `ErrorLogs` テーブルに該当ファイル情報とバイト数を含む警告ログが記録され、メディア処理キューには投入されないこと

#### Scenario: 255バイト以内の正常ファイルのスキャン

- **WHEN** すべての動画ファイルのファイル名単体の UTF-8 バイト数が 255 バイト以内である時
- **THEN** NAME_MAX 超過に関する警告ログは記録されず、通常通りメディア処理キューへ投入されてスキャンが正常終了する
