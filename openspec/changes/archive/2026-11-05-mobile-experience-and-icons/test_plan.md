## 5. E2Eテスト・画面検証ケース定義（Playwright）

| ケースID     | ジャーニー種別                               | 操作手順（Given → When）                                   | 期待される画面状態・出力エビデンス（Then）                                                     |
| :----------- | :------------------------------------------- | :--------------------------------------------------------- | :--------------------------------------------------------------------------------------------- |
| `E2E-MOB-01` | **PWA & アイコン認識**                       | モバイルエミュレーション (375x812) でアクセス              | `<head>` 内のファビコン・manifestタグがロードされ 404 がないこと                               |
| `E2E-MOB-02` | **Happy Path: モバイル一覧・表示切替・同期** | モバイル画面で表示切替トグルをタップ、同期アイコンをタップ | 2列グリッドとスリムリストが切り替わり、既存機能が維持されていること（スクリーンショット保存）  |
| `E2E-MOB-03` | **Happy Path: 全画面再生 & 連続視聴**        | サムネイルタップで動画再生、「次の動画」をタップ           | 余白ゼロの全画面プレイヤーが開き、次動画にシームレスに切り替わること（スクリーンショット保存） |
| `E2E-MOB-04` | **Happy Path: ランドスケープ表示**           | 再生中に画面を横向き (812x375) に回転                      | プレイヤーが画面全体に最大化フィットすること                                                   |
| `E2E-MOB-05` | **Zero-State: 動画0件初期状態**              | 動画0件の状態でモバイルアクセス                            | 崩れず「動画が見つかりません」メッセージが表示されること                                       |
| `E2E-MOB-06` | **Happy Path: 常設キーワード検索**           | 検索欄にフリーワードおよび `tag:xxx` を入力                | インクリメンタルに即時絞り込まれ、クリアボタンで復元すること                                   |
| `E2E-MOB-07` | **Happy Path: 表示・ソート設定シート**       | 表示設定ボタンからソート順やサムネON/OFFを変更             | 一覧の並び順やサムネ表示が即座に連動して反映されること                                         |
| `E2E-MOB-08` | **Happy Path: 各種子画面モーダルの操作**     | 統計、一括インポート、ルール等のモーダルを起動             | モバイル画面に収まり、入力やタブ切り替え、閉じる操作ができること                               |
| `E2E-MOB-09` | **Happy Path: タグ階層ブラウザ**             | 「全タグ」ボタンからタグ階層シートを開きタグ選択           | 階層ツリーが表示され、タグタップで動画が絞り込まれること                                       |
| `E2E-MOB-10` | **Happy Path: モバイルタグ作成・付与**       | 新規タグ作成モーダルでタグ作成、動画に付与                 | 新タグが作成され、動画カードに反映されること                                                   |
| `E2E-DSK-01` | **回帰検証: PCデスクトップ**                 | デスクトップ幅 (1280x800) でアクセス                       | 既存のツールバー・大中小グリッド・リストが従来通り動作すること                                 |
| `E2E-DSK-02` | **回帰検証: ページング**                     | デスクトップ幅でページング変更                             | ページャーが正しく動作すること                                                                 |
