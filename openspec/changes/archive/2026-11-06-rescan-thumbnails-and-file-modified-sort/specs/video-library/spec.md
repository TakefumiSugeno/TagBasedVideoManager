# Spec Delta: video-library

## MODIFIED Requirements

### Requirement: モバイル表示・ソート設定シート

システムは、モバイル画面において、並び替え基準（ファイル更新日【初期値】、TBVM登録日、ファイル名、ファイルサイズ、再生回数、再生時間）、昇順/降順、サムネイル表示切り替え、および読み込みモード（ページング vs 順次追加読み込み）を指先で容易に変更可能なスライド式設定シートを提供しなければならない（SHALL）。

#### Scenario: 設定シートでのファイル更新日時ソートの指定

- **WHEN** モバイルユーザーが表示設定シートを開き、並び替え基準に「ファイル更新日」を選択したとき
- **THEN** 現在の表示モードにかかわらず、動画のファイル更新日時に従って一覧が即座に並び替えられること

#### Scenario: 設定シートでの並び替え条件変更

- **WHEN** ユーザーが表示設定シートを開き、並び替え基準や昇順/降順を変更した時
- **THEN** 現在の表示モード（2列グリッドまたはスリムリスト）にかかわらず、指定した順序で即座に一覧が並び替えられること。

## ADDED Requirements

### Requirement: 動画一覧のファイル更新日による並び替え

システムは、Web UI のデスクトップツールバーおよび動画一覧APIにおいて、動画ファイルの最終更新日時（`fileModifiedAt`）を既定（初期値）のソートキーとする昇順および降順の並び替え機能を提供しなければならない（SHALL）。選択肢の順序は「ファイル更新日（初期値）」、「TBVM登録日」、「ファイル名」、「ファイルサイズ」、「再生回数」、「再生時間」の順で提供しなければならない（SHALL）。データベース上で `FileModifiedAt` が未設定の古いレコードが存在する場合、システムのTBVM登録日時（`CreatedAt`）を安全にフォールバックとして採用し、ソート順の破綻を防止しなければならない（SHALL）。

#### Scenario: デスクトップツールバーでの更新日時ソート選択

- **WHEN** ユーザーがデスクトップツールバーの並び替えドロップダウンから「ファイル更新日」を選択したとき
- **THEN** 動画一覧が各動画のファイル最終更新日時の降順（既定）または昇順に従って再レンダリングされること

#### Scenario: 更新日時未設定レコードのフォールバック整列

- **WHEN** 一部の動画レコードで `FileModifiedAt` が未設定の状態で「ファイル更新日」ソートが実行されたとき
- **THEN** 当該レコードはシステムTBVM登録日時（`CreatedAt`）で代用されて整列され、エラーや未定義順序とならないこと
