## 4. 単体テスト：複合条件デシジョンテーブル（C2 / MC/DC 網羅）

### 対象ロジック: `Scanner.fs` の再処理判定 (`thumbMissing || durationMissing`)

```fsharp
let thumbMissing =
    match v.ThumbnailPath with
    | None -> true
    | Some path -> not (File.Exists(path))
let durationMissing = v.Duration = 0L
let needsReprocessing = thumbMissing || durationMissing
```
