# application-versioning Delta Specification

## MODIFIED Requirements

### Requirement: セマンティックバージョニング規則の準拠と独立管理

システムは、Web アプリケーションおよびデスクトップアプリケーション（AI File Renamer）において、SemVer 2.0.0（`X.Y.Z` 形式）に基づく独立したバージョン管理を行わなければならない（SHALL）。各桁の増分規則は、`X`（メジャー）を互換性のない破壊的変更（L3）またはユーザーからの明示的な指示、`Y`（マイナー）を後方互換性のある新機能追加・機能改善・仕様変更（L2）、`Z`（パッチ）を不具合修正・軽微な調整（L1）としなければならない（SHALL）。また、本機能導入時の初期バージョンは双方 `0.1.0` とし、本変更（`appsettings-unification-and-renamer-spinners`, L2 規模）の適用により Web アプリケーションは `0.2.0` → `0.3.0`、デスクトップアプリケーションは `0.1.0` → `0.2.0` へそれぞれ独立してインクリメントされなければならない（SHALL）。

#### Scenario: 初期バージョンの定義と独立性

- **WHEN** システムのバージョン管理が導入された初期状態において
- **THEN** Web アプリケーションおよびデスクトップアプリケーションの各プロジェクト定義に独立して `0.1.0` が設定されていること

#### Scenario: 変更規模またはユーザー指示に応じたカウントアップ

- **WHEN** OpenSpec において L2 規模の変更が適用された時
- **THEN** 変更対象アプリケーションの `Y`（マイナー）が 1 増加し、`Z` が 0 にリセットされること（本変更では Web が `0.3.0`、Renamer が `0.2.0` となること）
- **WHEN** ユーザーから明示的なメジャー更新指示があった時
- **THEN** 対象アプリケーションの `X`（メジャー）が 1 増加し、`Y` および `Z` が 0 にリセットされること
