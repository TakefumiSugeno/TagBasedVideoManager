# Spec Delta: viewing-analytics

## ADDED Requirements

### Requirement: 視聴分析モーダルデータ取得中におけるスピナー表示と Zero-State 誤表示防止

フロントエンド（Web UI）は、視聴分析モーダルを開いた際および各タブ（再生ランキング: `ranking`、おすすめ動画: `recommendations`、例外エラーログ: `logs`）の非同期データ取得を実行中、タブ内の中央にスピナーおよび「分析データを読み込み中...」を表示しなければならない（SHALL）。データ取得が完了するまでの間、データ件数が 0 件であっても「再生履歴がまだありません」等の Zero-State 画面を表示してはならない（SHALL NOT）。データ取得完了後、該当タブのデータ件数が 0 件である場合のみ Zero-State 画面を表示しなければならない（SHALL）。また、Zero-State 画面には「動画一覧に戻る」等の案内導線を提供しなければならない（SHALL）。

#### Scenario: 視聴分析モーダル初回開時のスピナー表示と Zero-State 抑止

- **WHEN** ユーザーが視聴分析モーダルを開き、非同期データ取得が実行中であるとき
- **THEN** 「再生履歴がまだありません」が表示されず、中央にスピナーと「分析データを読み込み中...」が表示されること

#### Scenario: 分析データ0件時の Zero-State 正常表示

- **WHEN** 視聴分析データ取得が完了し、該当タブのデータ件数が 0 件であるとき
- **THEN** スピナーが非表示となり、「再生履歴がまだありません」または「エラーログはありません」が表示されること

#### Scenario: タブ切り替え時のローディング表示

- **WHEN** ユーザーが分析モーダル内で別のタブに切り替え、対象タブのデータ取得が実行中であるとき
- **THEN** 対象タブの領域にスピナーが表示され、通信完了後にデータが描画されること

### Requirement: 視聴分析データ取得エラー時の Error-State 表示と再試行導線

フロントエンド（Web UI）は、視聴分析データの取得 API 通信が失敗（HTTP 5xx、ネットワーク切断、タイムアウト等）した場合、スピナーを解除し、モーダル内に「分析データの取得に失敗しました」というエラー表示および「再試行」ボタンを表示しなければならない（SHALL）。ユーザーが「再試行」ボタンをクリックした際、対象タブのデータ取得処理を再実行しなければならない（SHALL）。

#### Scenario: 分析データ取得失敗時のエラー表示と再試行導線

- **WHEN** 視聴分析 API が通信エラーで失敗したとき
- **THEN** スピナーが解除され、モーダル内にエラーメッセージと「再試行」ボタンが表示されること

#### Scenario: 分析再試行ボタンクリックによる再取得

- **WHEN** ユーザーが「再試行」ボタンをクリックしたとき
- **THEN** 再びスピナーが表示され、分析データ取得が再実行されること
