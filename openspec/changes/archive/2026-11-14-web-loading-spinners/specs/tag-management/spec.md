# Spec Delta: tag-management

## ADDED Requirements

### Requirement: タグ一覧の非同期ロード中におけるスピナー表示と Zero-State 誤表示防止

フロントエンド（Web UI）は、タグ一覧の非同期データ取得（初回ロード時、ディレクトリ同期後、タグ作成・編集・削除後）を実行中、サイドバーのタグ領域に小型スピナーおよび「タグ読み込み中...」を表示しなければならない（SHALL）。データ取得が完了するまでの間、タグ件数が 0 件であっても「登録されたタグはありません」という Zero-State 画面を表示してはならない（SHALL NOT）。データ取得完了後、タグ件数が 0 件である場合のみ Zero-State を表示しなければならない（SHALL）。また、Zero-State 表示時には、ユーザーが即座にタグを追加できるよう「タグ管理を開く」ボタンまたは導線を提供しなければならない（SHALL）。

#### Scenario: 初回ロード中のタグスピナー表示と Zero-State 抑止

- **WHEN** Web UI 初期化時にタグ一覧取得非同期通信が実行中であるとき
- **THEN** 「登録されたタグはありません」が表示されず、タグ用スピナーと「タグ読み込み中...」が表示されること

#### Scenario: タグ0件時の Zero-State 正常表示と追加導線

- **WHEN** タグ一覧取得非同期通信が完了し、タグ件数が 0 件であるとき
- **THEN** スピナーが非表示となり、「登録されたタグはありません」とともに「タグ管理を開く」ボタンが表示されること

#### Scenario: ディレクトリ同期やタグ操作後のスピナー表示

- **WHEN** ディレクトリ同期完了後や新規タグ作成後にタグ一覧の再取得が実行中であるとき
- **THEN** タグ領域にローディング状態が表示され、完了後に最新のタグ一覧へ更新されること

### Requirement: タグ一覧取得エラー時の Error-State 表示と再試行導線

フロントエンド（Web UI）は、タグ一覧取得 API 通信が失敗（HTTP 5xx、ネットワーク切断、タイムアウト等）した場合、スピナーを解除し、サイドバータグ領域に「タグの取得に失敗しました」というエラー表示および「再試行」ボタンを表示しなければならない（SHALL）。ユーザーが「再試行」ボタンをクリックした際、`fetchTags()` を再実行しなければならない（SHALL）。

#### Scenario: タグ取得失敗時のエラー表示と再試行導線

- **WHEN** タグ一覧取得 API が通信エラーで失敗したとき
- **THEN** スピナーが解除され、サイドバー内にエラーメッセージと「再試行」ボタンが表示されること

#### Scenario: タグ再試行ボタンクリックによる再取得

- **WHEN** タグエラー表示でユーザーが「再試行」ボタンをクリックしたとき
- **THEN** 再びローディング状態となり、タグ取得リクエストが再送されること
