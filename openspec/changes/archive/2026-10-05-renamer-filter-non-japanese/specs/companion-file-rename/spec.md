# Spec Delta

## ADDED Requirements

### Requirement: ファイル名に日本語を含まない動画の抽出オプション

システムは、動画ファイル走査時、ファイル名本体（拡張子を除くベース名）に日本語文字（ひらがな、カタカナ、CJK統合漢字）を含まないファイルのみを抽出対象とするフィルタオプションを提供しなければならない（SHALL）。
本オプションはGUIツールバー上のチェックボックス（「ファイル名に日本語を含まないもののみ抽出」）により有効・無効を切り替え可能とし、起動時の初期状態は無効（OFF）としなければならない（SHALL）。
本オプションが有効な場合、システムは「フルパス文字数 ≧ 抽出基準（閾値）」かつ「ファイル名本体に日本語文字が1文字も含まれない」ファイルのみを候補として抽出しなければならない（SHALL）。
本オプションが無効な場合は、ファイル名に含まれる言語文字にかかわらず、「フルパス文字数 ≧ 抽出基準（閾値）」の動画ファイルを抽出対象としなければならない（SHALL）。

#### Scenario: 日本語を含まないフィルタ有効時の抽出

- **WHEN** 「ファイル名に日本語を含まないもののみ抽出」オプションを有効にして走査を実行したとき
- **THEN** パス長が閾値以上かつファイル名本体にひらがな・カタカナ・漢字が1文字も含まれない動画ファイルのみが抽出され、ファイル名に日本語文字を1文字でも含む動画ファイルは候補一覧から除外されること

#### Scenario: 日本語を含まないフィルタ無効時の通常抽出

- **WHEN** 「ファイル名に日本語を含まないもののみ抽出」オプションを無効にして走査を実行したとき
- **THEN** ファイル名本体の言語文字にかかわらず、パス長が閾値以上のすべての動画ファイルが候補一覧に抽出されること

#### Scenario: 閾値0と組み合わせた全件抽出

- **WHEN** 抽出基準（閾値）を0に設定し、「ファイル名に日本語を含まないもののみ抽出」オプションを有効にして走査を実行したとき
- **THEN** パス長に関係なく、ファイル名本体に日本語を含まないすべての動画ファイルが候補一覧に抽出されること

#### Scenario: フォルダ名に日本語が含まれる場合の判定独立性

- **WHEN** 親ディレクトリなどのフォルダパスに日本語が含まれているが、ファイル名本体には日本語が含まれていない動画ファイルを走査したとき
- **THEN** フォルダパスの日本語に影響されることなく、ファイル名本体の判定のみに基づいて正しく抽出対象として扱われること
