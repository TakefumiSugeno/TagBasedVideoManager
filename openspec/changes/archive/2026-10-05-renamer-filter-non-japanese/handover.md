# 申し送り事項 (Handover): AI File Renamer 日本語除外抽出フィルタ (`renamer-filter-non-japanese`)

## 1. 概要

本ドキュメントは、ファイルリネームコンパニオンアプリ（`TagBasedVideoManager.Renamer`）において、「ファイル名に日本語を含まないもののみ抽出」するフィルタリング機能を追加した変更 `renamer-filter-non-japanese` に関する実装結果、設計決定事項、品質エビデンス、および今後の拡張性（テーマ②: スマホUI最適化への申し送り事項を含む）を整理した申し送り書です。

---

## 2. 実装完了のサマリ

- **アーキテクチャ & 設計方針**:
  - `Result` 型（鉄道指向プログラミング / ROP）による純粋な関数型エラーハンドリング。
  - Elmish MVU (Model-View-Update) パターンに準拠し、副作用のない一方向データフローを維持。
  - セッション限定の非永続設定として実装（設定ファイルへの自動保存は行わず、ユーザーの一時的な走査意図に対応）。
- **日本語判定ロジック (`FileScanner.fs`)**:
  - コンパイル済み正規表現（`Regex(@"[\p{IsHiragana}\p{IsKatakana}\p{IsCJKUnifiedIdeographs}]", RegexOptions.Compiled)`）を採用。
  - ファイル名本体（拡張子を除くベース名）のみを判定対象とし、親ディレクトリパスや拡張子（`.mp4` 等）に含まれる文字列による誤判定を完全排除。
  - パス長および動画拡張子の判定を先行して評価する短絡評価（ショートサーキット）により、正規表現の実行回数を最小化してパフォーマンスを担保。
- **UI実装 (`Views.fs` & `mockup.html`)**:
  - Row 1 抽出基準ボックス内の一時変更注記と該当件数表示の間に、縦区切り線とともに `[ ] ファイル名に日本語を含まないもののみ抽出` チェックボックスを配置。
  - Fluent Theme のダークモード配色（`textSub`）および 11px フォントサイズ、適切なマージンが `mockup.html` と一致。
  - **ユーザー指示の厳守**: 抽出結果行（BEFORE/AFTER カード）には「日本語あり/なし」等の判定バッジや表示は一切追加せず、シンプルな対比表示を維持。
- **テスト自動化 & 品質エビデンス**:
  - 単体テスト・状態遷移テスト・実画面レンダリング E2E テスト: **全104件中 104件 Pass（失敗0件、スキップ0件）**。
  - TDD（Red-Green-Refactor）サイクルを厳格に順守。
  - `HostWindow` + `RenderTargetBitmap` による実画面レンダリングおよびキャプチャ出力（`E2E_10_Filter_Non_Japanese_Enabled.png`）を検証。
  - TRX テストレポート（`test/TestResults/TestRun_2026-10-04_17_22_55/TestRun_2026-10-04_17_22_55_net10.0.trx`）および HTML レポート（`CoverageReport/index.html`）を出力済み。

## 3. 既知の課題・技術的負債

### 3.1 NuGet 脆弱性警告 (`Tmds.DBus.Protocol` 0.20.0)

- **内容**: Avalonia 11.2.5 の Linux 向け推移的依存関係である `Tmds.DBus.Protocol` 0.20.0 に対し、既知の脆弱性（GHSA-xrw6-gwf8-vvr9）警告が出力される。
- **影響と対処**: 本アプリは Windows デスクトップ環境を主対象としており、DBus プロトコルは Windows 上では動作しないため実害はありません。今後の Avalonia マイナーアップデートで対応予定。

### 3.2 Web プロジェクト側の Playwright E2E テストのローカル実行環境

- **内容**: バックエンド Web プロジェクト（`test/TagBasedVideoManager.Tests`）の一部の E2E テストで、ローカル環境に Playwright のブラウザバイナリが未インストールの場合はテストがスキップ/エラーとなる。
- **対処**: 本 Change（Renamer）のテストスイート（104件）は完全に独立しており、100% 成功しているため影響はありません。Web 側の Playwright テストを実行する場合は `pwsh bin/Debug/net10.0/playwright.ps1 install` を実行すること。
