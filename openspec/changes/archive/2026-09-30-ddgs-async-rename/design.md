# Design: ddgs-async-rename

## Context

`TagBasedVideoManager.Renamer` は F# (.NET 10) + Avalonia.FuncUI (Elmish MVU) アーキテクチャを採用しています。現行の実装では、長パス抽出後に全候補を1つのJSON配列としてOpenRouter APIに送信し、全件のレスポンスが揃ってから一度に画面を更新する方式をとっていました。

本変更では、Pythonライブラリ `ddgs` (DuckDuckGo Search) によるWeb検索結果をLLMのコンテキストに付与し、さらにスキャン直後の即時IO描画とファイルごとの非同期逐次描画（行アニメーション付き）、3行常時表示、およびAFTERラベルの文字数抵触警告を実装します。

## Goals / Non-Goals

**Goals:**

- Pythonスクリプト `scripts/ddgs_search.py` を非同期呼び出しし、DuckDuckGo検索結果（上位スニペット）をJSONで取得・LLMへ注入する連携機構。
- スキャン完了時の全件即時IO描画（1回目の画面反映）。
- 制御された並行キュー（1〜2並行）によるファイルごとの非同期提案と、完了ごとの行単位の即時更新描画。
- 処理中行に対するアニメーション表示（インジケーター / プログレスバー）。
- 「BEFORE」「AFTER」「AI COMMENT」の3行常時固定表示レイアウト。
- AFTER行の緑色基調デザインと、文字数抵触（閾値超過）時における左側ラベルバッジ「AFTER (〇〇字 [危険])」の背景色赤化警告。

**Non-Goals:**

- Pythonや `ddgs` ライブラリの自動インストーラー（Python未導入時は安全にスキップして通常提案へフォールバック）。
- DuckDuckGo以外の検索エンジンの追加。

## Decisions

### 1. Python CLI スクリプト (`scripts/ddgs_search.py`) 経由での `ddgs` 呼び出し

- **Rationale**: `ddgs` ライブラリ（https://pypi.org/project/ddgs/）は頻繁なDuckDuckGoの仕様変更やBot対策を吸収して安定した検索結果を返します。独立したPythonスクリプトを用意し、F# から引数渡しでサブプロセス実行してJSON出力を受け取る方式が最も堅牢で保守性が高くなります。
- **Alternatives considered**:
  - .NET ネイティブでのHTMLスクレイピング: DuckDuckGo側のBotブロックに引っかかりやすくメンテナンス不能。
  - Python.NET: .NETランタイムとの密結合が発生し、ネイティブDLL依存や環境構築のトラブルが多い。

### 2. ファイル単位の非同期逐次パイプラインと並行度制御 (Concurrency: 1〜2)

- **Rationale**: DuckDuckGoは短時間の大量アクセスに対して一時的なアクセス制限（Rate limit / 429）を設けています。また、OpenRouter APIの無料モデル枠でも連続リクエストへの考慮が必要です。ファイル単位で1〜2並行のセマフォ（`SemaphoreSlim`）を用いて逐次処理し、完了したものから即座に Elmish の `CandidateAiProposed` メッセージを dispatch して `model.Candidates` の該当レコードを更新します。
- **Alternatives considered**:
  - 全件一括でLLMにWeb検索を行わせる（Function Calling）: 無料枠モデルでのツール呼び出しは精度が低く、全件分のWeb検索を行うとプロンプトが肥大化してタイムアウトするリスクが高い。

### 3. 3行常時固定表示レイアウト（Verticalモード）

- **Rationale**: BEFORE、AFTER、AI COMMENTの3行を常に固定高さで確保することで、画面表示のガタつきを排除し、ユーザーが各行の命名根拠を素早く確認できるようにします。
- **Alternatives considered**:
  - 従来通り例外時のみAIコメントを表示: どのWeb検索結果が使われたか、なぜその短縮名になったかがユーザーに伝わらない。

### 4. AFTERラベルバッジの赤色警告と全体緑色基調

- **Rationale**: AFTER行全体を赤くするのではなく、行全体および入力欄は緑色（エメラルド基調）を保ちつつ、閾値抵触時のみ左側の「AFTER (〇〇字 [危険])」ラベルバッジの背景色を赤色（危険色: `#450a0a` / `#ef4444`）に切り替えます。これにより、安全なファイルとの区別が直感的になり、UIの視覚的調和も保たれます。

### 5. AI提案中におけるリネーム実行ボタンの非活性化制御 (パターンA)

- **Rationale**: スキャン直後の即時IO描画により、画面上には全ファイルが元ファイル名のまま一覧表示されます。この提案処理中にリネームボタンを活性化させてしまうと、まだAI短縮が行われていない危険なパス長のまま誤ってリネームされてしまう事故のリスクが生じます。全ファイルのAI提案が完了するまでリネーム実行ボタン（「リネームのみ実行」「リネーム＆Docker再起動」）を非活性（Disabled）とすることで、100%の安全性を担保します。また、処理中はフッターに進捗状況（「AI提案中... (〇/〇件完了)」）を表示して待ち時間の透明性を確保します。
- **Alternatives considered**:
  - 提案完了分のみ随時実行可能（パターンB）: 早く完了したファイルからリネームできる利点はあるが、未提案ファイルの除外管理や処理中タスクのキャンセルが必要となり、ユーザーの誤認リスクも残る。

### 6. AI提案のキャンセル機構 (CancellationTokenSource) と新条件でのリスタート

- **Rationale**: ユーザーが提案処理の途中で「フォルダパスや閾値を間違えた」「命名規則を変えたい」「Web検索のON/OFFを切り替えたい」と気づいた場合、全件の完了を待たされることなく、直ちに処理をストップまたは新条件でリスタートできるようにします。`CancellationTokenSource` による非同期タスクの即時キャンセル機構を導入し、UIのツールバーには「⏹ 中止」ボタンを常時配置（待機中は非活性・提案処理中のみ活性化）することで、ボタン出現・消滅によるレイアウトのガタつき（レイアウトシフト）を完全に防止します。さらに、AI提案中であっても「抽出＆AI提案を実行」ボタンを常時活性としておくことで、新条件を指定してクリックした瞬間に前回の非同期パイプラインを自動キャンセルして新しい条件で即座に再実行できるように設計します。
- **Alternatives considered**:
  - AI提案中はツールバー全体を操作不可（モーダルロック）にする: ユーザーが設定ミスをした際に完了まで強制的に待たされ、UXが極めて悪化するため不採用。

## UI / UX モックアップ

本機能のインタラクティブな画面モックアップは [`mockup.html`](file:///D:/programming/repos/MyGitHubRepos/TagBasedVideoManager/openspec/changes/ddgs-async-rename/mockup.html) として作成されています。ブラウザで開くことで、即時IO描画、非同期行アニメーション、3行常時表示、および文字数抵触時のAFTERラベル赤化警告のインタラクションを直接検証できます。

### ① スキャン直後（即時IO描画・待機中）

```
+-------------------------------------------------------------------------------------------------+
| [x] #1  C:\Videos\Drama\                                                254字 [危険]  ⚠️ 未短縮 |
+-------------------------------------------------------------------------------------------------+
| [ BEFORE (254字 [危険]) ]  Extremely.Long.Filename.Sample.Episode.01.2026.1080p...       [.mp4] |
| [ AFTER  (254字 [未提案]) ] Extremely.Long.Filename.Sample.Episode.01.2026.1080p...       [.mp4] |
| [ AI COMMENT            ]  (AI提案の開始を待機しています...)                                    |
+-------------------------------------------------------------------------------------------------+
```

### ② 処理中（Web検索中 または LLM生成中 - 行アニメーション）

```
+-------------------------------------------------------------------------------------------------+
| [x] #1  C:\Videos\Drama\                                                254字 [危険]  🌐 検索中 |
+-------------------------------------------------------------------------------------------------+
| [ BEFORE (254字 [危険]) ]  Extremely.Long.Filename.Sample.Episode.01.2026.1080p...       [.mp4] |
| [ AFTER  (生成中...)    ]  [================== ⠋ 処理中 (ddgs検索中...) ==================] [.mp4] |
| [ AI COMMENT            ]  Web検索から公式タイトル情報を収集中...                               |
+-------------------------------------------------------------------------------------------------+
```

### ③ 提案完了（安全に短縮できた場合 - AFTERラベルは緑）

```
+-------------------------------------------------------------------------------------------------+
| [x] #1  C:\Videos\Drama\                                      -44字 (17%短縮)  ✓ 安全   [AI提案済]|
+-------------------------------------------------------------------------------------------------+
| [ BEFORE (254字 [危険]) ]  Extremely.Long.Filename.Sample.Episode.01.2026.1080p...       [.mp4] |
| [ AFTER  (210字 [安全]) ]  Sample Drama S01E01 (2026)                                    [.mp4] |
| [ AI COMMENT            ]  ddgs検索より正式タイトル「Sample Drama」を特定し短縮しました。         |
+-------------------------------------------------------------------------------------------------+
  ※ AFTERラベル「AFTER (210字 [安全])」の背景色は【緑色 (エメラルド)】
```

### ④ 提案完了（短縮後も基準文字数を超過している場合 - AFTERラベルだけ赤！）

```
+-------------------------------------------------------------------------------------------------+
| [x] #2  C:\Videos\LongPathDir\                                245字 [危険]  ⚠️ 要短縮   [AI提案済]|
+-------------------------------------------------------------------------------------------------+
| [ BEFORE (258字 [危険]) ]  Another.Very.Long.Path.Filename.Over.Limit.Sample.1080p...     [.mp4] |
| [ AFTER (245字 [危険])! ]  Sample Another Very Long Title Edition 2026 Remaster          [.mp4] |
| [ AI COMMENT            ]  副題を含めたため閾値(240字)を超過しています。手動で削ってください。   |
+-------------------------------------------------------------------------------------------------+
  ※ AFTERラベル「AFTER (245字 [危険])」の背景色だけを【赤色 (クリムゾン/レッド)】に変更！
```

## Risks / Trade-offs

- **[Risk: DuckDuckGo のレートリミット]** → 並行度を1〜2に制限し、ファイル間に 500ms 程度のインターバルを設定する。
- **[Risk: Pythonまたはddgsの未導入]** → スクリプト起動エラー時に例外を握りつぶし、Web検索を自動スキップして通常のAIプロンプトで継続処理する。AIコメントに「⚠️ ddgs未導入のためWeb検索をスキップ」と明示する。
- **[Risk: ユーザーが大量ファイルを一括処理する際のUI負荷]** → 1件ごとにUI再描画が行われるが、Avalonia.FuncUIの差分レンダリングにより該当行のみが効率的に更新される。
