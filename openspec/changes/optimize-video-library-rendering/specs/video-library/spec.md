# Spec Delta: video-library

## ADDED Requirements

### Requirement: 動画一覧および検索結果におけるタグ情報の一括取得

システムは、動画一覧 API（`GET /api/videos`）および検索 API（`GET /api/videos?q=...`）において、動画ごとに個別のタグ取得クエリを発行（直列 N+1 クエリ）してはならず（SHALL NOT）、対象となる全動画のタグ情報を単一の一括クエリで取得し、メモリ上で各動画レコードへ結合して返却しなければならない（SHALL）。

#### Scenario: 複数動画の一括タグ結合返却

- **WHEN** データベースにタグが紐付いた複数の動画が存在する状態で動画一覧 API が要求されたとき
- **THEN** 直列クエリによる遅延なく、各動画に正しいタグ情報（Id, Name, ColorCode, ParentId）が付与された JSON 配列が返却されること

#### Scenario: タグ未紐付け動画が混在する場合の一括取得

- **WHEN** タグが付与された動画とタグ未付与（0件）の動画が混在するライブラリ一覧が要求されたとき
- **THEN** タグ未付与の動画は空配列（`tags: []`）となり、タグ付き動画には正確にタグが紐付いて全件が返却されること

#### Scenario: 0件時の安全な一括取得

- **WHEN** 検索条件に一致する動画が 0 件の状態で検索 API が呼び出されたとき
- **THEN** タグ取得の一括クエリでエラーや例外が発生せず、空配列（`[]`）が即座に返却されること

### Requirement: サムネイル画像の遅延読み込みとブラウザ負荷軽減

フロントエンド（Web UI）は、デスクトップおよびモバイルにおけるグリッド表示およびリスト表示のすべての動画サムネイル画像要素において、遅延読み込み属性（`loading="lazy"`）および非同期デコード属性（`decoding="async"`）を適用し、ビューポート外の画像リクエストによるネットワーク・I/O 負荷を抑制しなければならない（SHALL）。

#### Scenario: ビューポート外サムネイルの遅延ロード

- **WHEN** ユーザーが動画ライブラリ画面を開いたとき
- **THEN** 画面初期表示領域外にある動画カードのサムネイル画像は即座にリクエストされず、スクロール等で表示領域に近づいた時点で順次読み込まれること
