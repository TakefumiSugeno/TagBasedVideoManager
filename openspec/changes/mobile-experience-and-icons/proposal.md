# Proposal: mobile-experience-and-icons

- **規模レベル**: L2 (通常: 機能追加・UI仕様変更)
- **変更種別**: feat
- **関連Issue**: #12 (アプリアイコン・ファビコン生成), #13 (スマホ対応)

## Why

TagBasedVideoManager の Web インターフェースは PC デスクトップを主対象として構築されており、スマートフォンなどのタッチデバイスからアクセスした際に「ツールバーによる画面圧迫」「ホバー依存の操作」「小さなタップ領域」「アドレスバー伸縮によるレイアウト崩れ」などの課題が存在します。また、ファビコンやアプリアイコンが未設定（404）のため、スマホのホーム画面追加やブラウザタブでの視認性が確保されていません。
さらに、モバイルにおいて動画を探し管理するための「キーワード・DSL検索」「階層的なタグ検索」「スマホ上での新規タグ作成・付与」「ソートやページング等の表示設定」が欠落することなく、レイアウト切り替え（2列グリッド/スリムリスト）時にもすべての既存機能が維持され、各子画面（モーダル）がモバイル最適化された形で快適に操作できる環境が求められています。
本変更では、ブランドアイコンおよび PWA (Web App Manifest) 基盤を整備し、スマホでの動画視聴・再生アクセシビリティを最優先としつつ、検索・タグ管理・各種子画面を含む完全なモバイル体験を提供します。

## What Changes

- **Web ブランディング & PWA 対応 (Issue #12)**:
  - ブランドシンボル（Tag + Play を基調とした Indigo/Violet グラデーション）の策定。
  - Web 用アセット生成: `favicon.svg`, `favicon.ico` (マルチサイズ), `apple-touch-icon.png` (180x180), `icon-192.png`, `icon-512.png`。
  - `manifest.webmanifest` (Web App Manifest) の配置と HTML 連携による、ホーム画面追加時のスタンドアロン全画面起動対応。
- **再生・検索・タグ管理を両立する完全モバイル UI (Issue #13)**:
  - **常設キーワード検索欄**: ヘッダー直下に配置し、フリーワードおよび `tag:xxx` などの DSL 検索にインクリメンタル対応（クリアボタン付き）。
  - **タグ検索・階層ブラウザ & タグ作成**: クイックタグピルに加え、下からスライドする「タグ階層ブラウザ」から全タグ検索・階層ツリー選択が可能。さらにスマホ上で完結する「新規タグ作成」機能を提供。
  - **既存機能を欠落させない表示切り替え**:
    - 2列グリッド（ギャラリー風）とスリムリスト（高密度エクスプローラー風）の相互切り替え。
    - 切り替え時もソート（登録日/ファイル名/再生数/時間）、サムネイルON/OFF、ページング/順次追加読み込み、再生数リセット、お気に入り、複数選択などの既存機能を完全に維持。
    - 「表示・ソート設定シート」により、スマホでも全ての表示条件を親指で変更可能。
  - **全画面没入型動画プレイヤー**:
    - 余白のない全画面モーダルとして表示し、横向き（ランドスケープ）への自動追従に対応。
    - プレイヤー内に「前の動画 ◀」「次の動画 ▶」コントロールを常備し、一覧に戻らず連続視聴可能に。
  - **各種子画面（モーダル）のモバイル完全対応**:
    - タグ管理、動画へのタグ付与、一括タグ操作、統計・おすすめ、一括インポート/エクスポート、自動適用ルール、スマートフォルダ保存の全モーダルをモバイル幅で崩れず操作できるようレスポンシブ化。
  - **タッチ操作性とレイアウト堅牢化**:
    - タッチターゲットの最小 44x44px 確保。
    - `100dvh` および safe-area-inset による iOS/Android のアドレスバー伸縮・ノッチ対策。

## Non-goals

- Avalonia デスクトップアプリ (`TagBasedVideoManager.Renamer`) のアプリアイコン変更（別Issue/別アイコンとして扱う）。
- Service Worker によるオフライン動画キャッシュ（動画ストリーミングが本質のため、今回は Web App Manifest によるスタンドアロン起動に留める）。

## Capabilities

### New Capabilities

- `web-branding-and-pwa`: ファビコン、apple-touch-icon、PWA 用アイコンおよび Web App Manifest によるホーム画面追加・スタンドアロン全画面起動の提供。

### Modified Capabilities

- `video-library`: モバイル端末向けの常設キーワード検索、2列グリッド/スリムリスト表示切り替え、既存表示設定（ソート・サムネ・ページング）の完全維持、全画面プレイヤーでの前後動画移動、各種モーダルのモバイル対応、safe-area / 100dvh 考慮のレスポンシブ体験の提供。
- `tag-management`: モバイル端末向けのタグ階層ブラウザ、インクリメンタルタグ検索、スマホ完結の新規タグ作成・編集、および動画個別へのタグ付与モーダルの提供。

## Acceptance Criteria

- **AC-1 (ファビコン & PWA)**:
  - Given: ユーザーがブラウザで Web アプリにアクセスした時
  - When: タブまたはブックマークを確認した時
  - Then: 404 エラーなくファビコンが表示され、スマホで「ホーム画面に追加」した際にアプリアイコンとスタンドアロン全画面（URLバー非表示）で起動できること。
- **AC-2 (常設検索 & タグ階層検索・作成)**:
  - Given: モバイルメイン画面を表示している時
  - When: 検索欄への入力、または「全タグ」シートからタグ選択/新規タグ作成を行った時
  - Then: キーワードおよびDSL（`tag:xxx`）で即座に絞り込まれ、新規作成したタグが即座に一覧および動画付与で利用可能となること。
- **AC-3 (表示切り替えと既存機能の維持)**:
  - Given: モバイル画面幅（< 640px）で動画一覧を表示している時
  - When: 表示切り替えボタンをタップ、または表示設定シートからソート・サムネイルON/OFF・ページングを変更した時
  - Then: 既存の機能（ソート、サムネイル表示制御、ページネーション、再生回数リセット等）が欠落することなく、2列グリッドとスリムリストの間で正しく反映・切り替わること。
- **AC-4 (全画面プレイヤー & 連続視聴)**:
  - Given: モバイル端末で動画をタップした時
  - When: プレイヤーが起動した時
  - Then: 画面いっぱいのプレイヤーが起動し、「前の動画」「次の動画」ボタンで一覧に戻ることなく前後の動画を再生できること。
- **AC-5 (子画面のモバイル完全動作)**:
  - Given: 各種メニュー（統計、インポート、ルール、スマートフォルダ、タグ付与、一括操作等）を開いた時
  - When: モバイル画面上で操作した時
  - Then: 画面外にはみ出したり操作不能になることなく、正常に入力・実行・完了できること。

## Impact

- **フロントエンド (`src/TagBasedVideoManager/wwwroot/`)**:
  - `index.html`: ヘッダー、常設検索欄、クイックタグピル、タグ階層シート、表示設定シート、2列グリッド/スリムリスト、全画面プレイヤー、各種子画面（モーダル）のモバイル最適化。
  - `app.css`: safe-area, dvh, タップ領域、スクロールバー非表示、モーダル用のスタイル調整。
  - `manifest.webmanifest`: 新規追加。
  - 静的アイコンアセット (`favicon.svg`, `favicon.ico`, `apple-touch-icon.png`, `icon-192.png`, `icon-512.png`): 新規追加。
- **破壊的変更 (BREAKING)**:
  - なし（デスクトップブラウザでの既存の閲覧・管理機能はすべて完全維持）。
