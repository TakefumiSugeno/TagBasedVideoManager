# Proposal: mobile-experience-and-icons

- **規模レベル**: L2 (通常: 機能追加・UI仕様変更)
- **変更種別**: feat
- **関連Issue**: #12 (アプリアイコン・ファビコン生成), #13 (スマホ対応)

## Why

TagBasedVideoManager の Web インターフェースは PC デスクトップを主対象として構築されており、スマートフォンなどのタッチデバイスからアクセスした際に「ツールバーによる画面圧迫」「ホバー依存の操作」「小さなタップ領域」「アドレスバー伸縮によるレイアウト崩れ」などの課題が存在します。また、ファビコンやアプリアイコンが未設定（404）のため、スマホのホーム画面追加やブラウザタブでの視認性が確保されていません。
本変更では、ブランドアイコンおよび PWA (Web App Manifest) 基盤を整備し、スマホでの動画視聴・再生アクセシビリティを最優先としたレスポンシブ UI（2列グリッド/スリムリスト切り替え、全画面プレイヤー、前後動画移動）を提供することで、スマホから直感的かつ快適に動画を楽しめる体験を実現します。

## What Changes

- **Web ブランディング & PWA 対応 (Issue #12)**:
  - ブランドシンボル（Tag + Play を基調とした Indigo/Violet グラデーション）の策定。
  - Web 用アセット生成: `favicon.svg`, `favicon.ico` (マルチサイズ), `apple-touch-icon.png` (180x180), `icon-192.png`, `icon-512.png`。
  - `manifest.webmanifest` (Web App Manifest) の配置と HTML 連携による、ホーム画面追加時のスタンドアロン全画面起動対応。
- **再生アクセシビリティ最優先のモバイル UI (Issue #13)**:
  - **メイン画面ヘッダーの整理**: アプリタイトルに加え、手元ですぐ最新化できる「ディレクトリ同期」ボタン、表示切り替えトグル、お気に入りフィルタ、メニュー [≡] を配置。重い管理項目（生成停止・インポート・ルール設定等）はメニュー内へ退避。
  - **クイックタグフィルタ**: 画面上部に親指でスムーズに選べる横スクロールのタグピルを配置。
  - **2 つのモバイル表示モード**:
    - **2列グリッド型 (ギャラリー風)**: サムネイル重視で写真アプリのように直感的に動画を一覧。
    - **スリムリスト型 (高密度エクスプローラー風)**: ファイル名と再生時間・タグを 1 行に凝縮し、大量の動画を高速スクロールで一覧。
    - ワンタップで相互に即時切り替え可能。
  - **全画面没入型動画プレイヤー**:
    - モバイル幅では余白のない全画面モーダルとして表示し、横向き（ランドスケープ）への自動追従に対応。
    - プレイヤー内に「前の動画 ◀」「次の動画 ▶」コントロールを常備し、一覧に戻らず連続視聴可能に。
  - **タッチ操作性とレイアウト堅牢化**:
    - タッチターゲットの最小 44x44px 確保。
    - `100dvh` および safe-area-inset による iOS/Android のアドレスバー伸縮・ノッチ対策。

## Non-goals

- Avalonia デスクトップアプリ (`TagBasedVideoManager.Renamer`) のアプリアイコン変更（別Issue/別アイコンとして扱う）。
- Service Worker によるオフライン動画キャッシュ機能（ストリーミング中心のため、今回は Web App Manifest によるスタンドアロン起動に留める）。
- スマホ上での高度なタグ階層編集や正規表現自動ルールの複雑な編集機能（スマホでは閲覧・再生・タグ付与・お気に入りを主目的とし、構造管理は PC を推奨）。

## Capabilities

### New Capabilities

- `web-branding-and-pwa`: ファビコン、apple-touch-icon、PWA 用アイコンおよび Web App Manifest によるホーム画面追加・スタンドアロン全画面起動の提供。

### Modified Capabilities

- `video-library`: モバイル端末向けの 2 列グリッドおよびスリムリストの表示切り替え、全画面プレイヤーでの前後動画移動、safe-area / 100dvh 考慮のレスポンシブ再生体験の提供。

## Acceptance Criteria

- **AC-1 (ファビコン & PWA)**:
  - Given: ユーザーがブラウザで Web アプリにアクセスした時
  - When: タブまたはブックマークを確認した時
  - Then: 404 エラーなくファビコンが表示され、スマホで「ホーム画面に追加」した際にアプリアイコンとスタンドアロン全画面（URLバー非表示）で起動できること。
- **AC-2 (2列グリッド & スリムリスト切り替え)**:
  - Given: モバイル画面幅（< 640px）で動画一覧を表示している時
  - When: 表示切り替えボタンをタップした時
  - Then: サムネイル重視の 2 列グリッド表示と、高密度なスリムリスト表示が瞬時に相互に切り替わること。
- **AC-3 (全画面プレイヤー & 連続視聴)**:
  - Given: モバイル端末で動画をタップした時
  - When: プレイヤーが起動した時
  - Then: 画面いっぱいのプレイヤーが起動し、「前の動画」「次の動画」ボタンで一覧に戻ることなく前後の動画を再生できること。
- **AC-4 (ディレクトリ同期ボタンの即時利用)**:
  - Given: モバイルのメイン画面にいる時
  - When: ヘッダーの同期アイコンをタップした時
  - Then: ディレクトリ同期が実行され、スキャン中インジケーターが表示された後、最新動画が反映されること。

## Impact

- **フロントエンド (`src/TagBasedVideoManager/wwwroot/`)**:
  - `index.html`: `<head>` 内のアイコン・manifestタグ追加、ヘッダー/ツールバー/動画一覧/プレイヤーのレスポンシブ・Alpine.js 構造更新。
  - `app.css`: safe-area, dvh, タップ領域、marquee, プレイヤー用のスタイル調整。
  - `manifest.webmanifest`: 新規追加。
  - 静的アイコンアセット (`favicon.svg`, `favicon.ico`, `apple-touch-icon.png`, `icon-192.png`, `icon-512.png`): 新規追加。
- **バックエンド (`src/TagBasedVideoManager/`)**:
  - 静的ファイルミドルウェアで `.webmanifest` の MIME タイプが適切に配信されることの確認（Giraffe / ASP.NET Core）。
- **破壊的変更 (BREAKING)**:
  - なし（デスクトップブラウザでの既存の閲覧・管理機能はすべて維持）。
