# Spec Delta: tag-management

## ADDED Requirements

### Requirement: モバイル向けタグ階層ブラウザおよび新規タグ作成UI

システムは、モバイル端末においてタグ階層ツリーの閲覧、インクリメンタル検索、タグ選択による動画一覧の即時絞り込みが可能なボトムシート型タグブラウザを提供しなければならない（SHALL）。また、モバイル画面および動画へのタグ付与モーダルから直接新しいタグを作成し、即座に一覧および選択肢へ反映可能にしなければならない（SHALL）。

#### Scenario: モバイルタグ階層ブラウザでのタグ選択絞り込み

- **WHEN** ユーザーがモバイル画面上でタグブラウザを開き、任意のタグを選択した時
- **THEN** タグブラウザが閉じ、選択されたタグに基づく動画一覧の絞り込み表示が即座に実行されること。

#### Scenario: モバイル画面からの新規タグ作成と即時反映

- **WHEN** ユーザーがモバイルのタグ作成モーダルでタグ名、カラーコード、親タグを指定して保存を実行した時
- **THEN** タグ作成APIが呼び出され、作成されたタグが即座にクイックタグピルおよび階層ツリーに追加表示されること。

#### Scenario: 動画へのタグ付与モーダルからの新規タグ作成

- **WHEN** 単一動画のタグ付与モーダル内から「新規タグ作成」を実行した時
- **THEN** タグ作成が完了し、モーダルを閉じることなく該当動画へ新タグを即時紐付け可能であること。
