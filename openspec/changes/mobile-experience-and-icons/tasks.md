# Tasks: mobile-experience-and-icons

## 1. ブランディング & PWA 基盤の作成

- [ ] 1.1 ブランドロゴシンボル（Tag + Play）をデザインし、`favicon.svg` を作成して `src/TagBasedVideoManager/wwwroot/` に配置する。ブラウザで SVG が正常に描画されることを確認する。
- [ ] 1.2 `favicon.svg` からマルチサイズ ICO (`favicon.ico`: 16/32/48) および PNG (`apple-touch-icon.png`: 180x180, `icon-192.png`: 192x192, `icon-512.png`: 512x512) を生成して配置する。ファイルサイズと解像度を確認する。
- [ ] 1.3 `manifest.webmanifest` を作成し、アイコン定義、スタンドアロンモード (`display: standalone`)、テーマカラー (`#030712`) を設定する。Giraffe から適切な MIME タイプ (`application/manifest+json`) で配信されることをテストで確認する。
- [ ] 1.4 `index.html` の `<head>` にファビコン、apple-touch-icon、manifest の `<link>` タグを追加し、ブラウザタブおよび開発者ツールで 404 が解消されていることを確認する。

## 2. モバイルレイアウト基盤 & メイン画面 UI 実装

- [ ] 2.1 `app.css` および `index.html` に `100dvh`、safe-area-inset、`viewport-fit=cover` を適用し、モバイル幅でのアドレスバー伸縮時にコンテンツが画面内に収まることを確認する。
- [ ] 2.2 メインヘッダーを最適化し、同期ボタン [🔄]、表示設定ボタン [🎛️]、表示切り替えトグル [⊞/≡]、お気に入りフィルタ [★]、メニュー [≡] を配置する。
- [ ] 2.3 ヘッダー直下に常設のキーワード検索入力欄（フリーワード・`tag:xxx` DSL 対応、クリアボタン付き）を実装し、インクリメンタル検索が動作することを確認する。
- [ ] 2.4 クイックタグピルバーに `[🏷️ 全タグ]` ボタンおよび `[+ 作成]` ボタンを配置し、タップでそれぞれタグブラウザ・タグ作成モーダルが起動することを確認する。
- [ ] 2.5 2列グリッド（ギャラリー風）とスリムリスト（高密度エクスプローラー風）の相互切り替えを実装し、切り替え時もソート順、サムネイル表示ON/OFF、再生数リセット、タグ付与、お気に入り、ページング等の既存機能が完全に維持されることを確認する。
- [ ] 2.6 「表示・ソート設定シート (`toolbarSheet`)」を実装し、並び替え基準（登録日/ファイル名/再生数/時間）、昇順/降順、サムネ表示ON/OFF、ページング vs 順次追加読み込みが変更できることを確認する。

## 3. タグ階層ブラウザ・タグ作成 & 各種子画面のモバイル最適化

- [ ] 3.1 ボトムスライド型の「タグ階層ブラウザ」を実装し、インクリメンタルタグ検索および階層ツリーからの選択絞り込みができることを確認する。
- [ ] 3.2 スマホ完結の「新規タグ作成・編集モーダル (`tagModal`)」を実装し、タグ名・カラーコード・親タグを指定して新規作成および更新ができることを確認する。
- [ ] 3.3 単一動画への「タグ付与モーダル (`addTagModal`)」および「一括タグ操作モーダル (`batchTagModal`)」をモバイル幅に対応させ、モーダル内からの新規タグ作成導線が動作することを確認する。
- [ ] 3.4 統計・おすすめ (`analyticsModal`)、一括インポート (`bulkModal`)、自動ルール (`ruleModal`)、スマートフォルダ (`smartFolderModal`)、およびシステム管理ドロワーの全子画面をモバイル最適化し、画面突き抜けなく操作できることを確認する。

## 4. モバイル全画面プレイヤー & 連続視聴ナビゲーション実装

- [ ] 4.1 動画プレイヤーモーダルをモバイル画面幅（< 640px）では余白ゼロの全画面没入型としてレンダリングし、横画面回転時に自動最大化フィットすることを確認する。
- [ ] 4.2 プレイヤーコントロールに「◀ 前の動画」「次の動画 ▶」ボタンを実装し、現在フィルタ・ソートされている動画順に一覧に戻らず連続再生できることを確認する。
- [ ] 4.3 主要タッチターゲットに最低 44x44px のタップ領域を確保し、誤タップなく操作できることを確認する。

## 5. 総合検証 & E2E テスト
