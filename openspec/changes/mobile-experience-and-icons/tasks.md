# Tasks: mobile-experience-and-icons

## 1. ブランディング & PWA 基盤の作成

- [ ] 1.1 ブランドロゴシンボル（Tag + Play）をデザインし、`favicon.svg` を作成して `src/TagBasedVideoManager/wwwroot/` に配置する。ブラウザで SVG が正常に描画されることを確認する。
- [ ] 1.2 `favicon.svg` からマルチサイズ ICO (`favicon.ico`: 16/32/48) および PNG (`apple-touch-icon.png`: 180x180, `icon-192.png`: 192x192, `icon-512.png`: 512x512) を生成して配置する。ファイルサイズと解像度を確認する。
- [ ] 1.3 `manifest.webmanifest` を作成し、アイコン定義、スタンドアロンモード (`display: standalone`)、テーマカラー (`#030712`) を設定する。Giraffe から適切な MIME タイプ (`application/manifest+json`) で配信されることをテストで確認する。
- [ ] 1.4 `index.html` の `<head>` にファビコン、apple-touch-icon、manifest の `<link>` タグを追加し、ブラウザタブおよび開発者ツールで 404 が解消されていることを確認する。

## 2. モバイルレイアウト基盤 & メイン画面 UI 実装

- [ ] 2.1 `app.css` および `index.html` に `100dvh`、safe-area-inset、`viewport-fit=cover` を適用し、モバイル幅でのアドレスバー伸縮時にコンテンツが画面内に収まることを確認する。
- [ ] 2.2 メインヘッダーをモバイル向けに最適化し、ディレクトリ同期ボタン [🔄]、表示切り替えトグル [⊞/≡]、お気に入りフィルタ [★]、メニュー [≡] を配置する。重い管理項目はメニュー内に退避されていることを確認する。
- [ ] 2.3 ヘッダー直下に横スクロール可能なクイックタグピルバーを実装し、タップ時に該当タグで即時フィルタリングされることを確認する。
- [ ] 2.4 Alpine.js に `mobileViewMode` 状態を追加し、サムネイル重視の「2列グリッド型」とファイル名重視の超高密度な「スリムリスト型」の描画を実装する。トグルタップで相互に即座に切り替わることを確認する。

## 3. モバイル全画面プレイヤー & 連続視聴ナビゲーション実装

- [ ] 3.1 動画プレイヤーモーダルをモバイル画面幅（< 640px）では余白ゼロの全画面没入型としてレンダリングし、横画面回転時に自動最大化フィットすることを確認する。
- [ ] 3.2 プレイヤーコントロールに「◀ 前の動画」「次の動画 ▶」ボタンを実装し、現在フィルタ・ソートされている動画順に一覧に戻らず連続再生できることを確認する。
- [ ] 3.3 お気に入りボタン（★）、閉じるボタン、再生ボタン等の主要タッチターゲットに最低 44x44px のタップ領域を確保し、誤タップなく操作できることを確認する。

## 4. 総合検証 & E2E テスト

- [ ] 4.1 モバイルビューポート（iPhone / Pixel 想定幅）を対象とした Playwright E2E テストを作成し、表示切り替え・全画面プレイヤー起動・連続視聴・ディレクトリ同期の全シナリオが PASS することを確認する。
- [ ] 4.2 全ユニットテスト・結合テストを実行し、テスト結果 TRX レポートおよびカバレッジレポートを出力して Gate 2 (Apply DoD) を検証する。
