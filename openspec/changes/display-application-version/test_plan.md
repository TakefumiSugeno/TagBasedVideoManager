| ケースID | 対象関数 / メソッド                  | 検証観点（区分）                      | 入力値・前提状態                 | 期待される出力・状態変化                                           |
| :------- | :----------------------------------- | :------------------------------------ | :------------------------------- | :----------------------------------------------------------------- |
| `UT-01`  | `HttpHandlers.formatAssemblyVersion` | 正常系（通常バージョン）              | `Some (Version(0, 1, 0, 0))`     | `"0.1.0"` が返却されること                                         |

## 6. E2Eテスト・画面検証ケース定義

| ケースID | ジャーニー種別                                 | 操作手順（Given → When）                                                                      | 期待される画面状態・出力エビデンス（Then）                                                                                                       |
| :------- | :--------------------------------------------- | :-------------------------------------------------------------------------------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------- |
| `E2E-01` | **Happy Path**（Web デスクトップ表示）         | デスクトップブラウザ（幅 1280px）でライブラリ画面を開く                                       | 画面ヘッダーのタイトル右横に `v0.1.0` バッジが描画され、タブタイトルが `Tag-Based Video Manager (v0.1.0)` となっていること（PNG キャプチャ保存） |
| `E2E-02` | **モバイル折り返し表示**                       | モバイルビューポート（幅 375px）でライブラリ画面を開く                                        | タイトルが折り返されてもバッジが画面外に突き抜けず、タイトル末尾に追従して表示されること（PNG キャプチャ保存）                                   |
| `E2E-03` | **Negative / Bulkhead 検証**（通信ハング耐性） | `/api/version` へのリクエストが 3 秒遅延（タイムアウト超過）または 500 で失敗するようにモック | 動画一覧やタグ一覧の初期化が一切ブロックされずに即時表示され、バッジは非表示フォールバックとなること（PNG キャプチャ保存）                       |
| `E2E-04` | **Happy Path**（デスクトップアプリ起動確認）   | AI File Renamer をビルド・実行する                                                            | コンソール起動ログに `TagBasedVideoManager - AI File Renamer v0.1.0 started` が出力され、ウィンドウが正常に立ち上がること                        |
