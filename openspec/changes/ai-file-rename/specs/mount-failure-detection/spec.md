# Spec Delta: mount-failure-detection

## Purpose

TagBasedVideoManager Webアプリケーションにおいて、動画ディレクトリのマウント状態（存在有無およびファイル件数）を監視し、パス長制限等によるマウント失敗や異常を検知した際にWeb UI上でユーザーへ明確な警告メッセージを提示する機能を提供する。

## ADDED Requirements

### Requirement: 動画ディレクトリのマウントヘルスチェック

システムは、サーバー起動時および定期スキャン時に環境変数 `VIDEO_DIR` で指定されたマウントパスの疎通とファイル件数を検査し、ディレクトリが存在しないかファイル件数が0件の場合に異常ステータスを記録しなければならない（SHALL）。

#### Scenario: マウント先が空の場合の異常検知

- **WHEN** サーバー起動時にマウント先ディレクトリが存在しないか、あるいは検出動画数が0件であったとき
- **THEN** システムはマウント異常（MountAnomaly）状態としてマークし、ヘルスチェックAPIおよび起動ログに警告を出力すること

### Requirement: Web UIでのマウントエラー警告バナー表示

システムは、マウント異常が検知されている場合、Web画面の最上部に目立つ警告バナーを表示し、ホスト側のDesktop Companionアプリによるリネーム実行を案内しなければならない（SHALL）。

#### Scenario: ユーザー画面での警告表示

- **WHEN** ユーザーがブラウザでTagBasedVideoManagerのトップページを開いた際、マウント異常状態であるとき
- **THEN** 画面上部に「動画ディレクトリのマウントに失敗しているか空です。パス長制限等の可能性があるため、Desktop Companionアプリで確認・リネームを実行してください」という警告バナーが表示されること
