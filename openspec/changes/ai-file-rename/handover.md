## 3. 既知の課題・技術的負債

### 3.1 NuGet 脆弱性警告 (`Tmds.DBus.Protocol` 0.20.0)

- **内容**: Avalonia 11.2.5 の Linux 向け推移的依存関係である `Tmds.DBus.Protocol` 0.20.0 に対し、既知の脆弱性（GHSA-xrw6-gwf8-vvr9）警告が出力される。
- **影響と対処**:
  - 本アプリは Windows デスクトップ環境を主対象としており、DBus プロトコルは Windows 上では動作しないため実害はありません。
  - 今後 Avalonia のマイナーアップデート（11.3.x 等）で依存パッケージが更新されたタイミングで NuGet パッケージを更新することを推奨します。

### 3.2 OpenRouter API キー未設定時の動作

- **内容**: `OPENROUTER_API_KEY` 環境変数または設定ファイルに API キーが存在しない場合、AI提案リクエスト時に `OpenRouterError (401, "API Key not configured")` が発生します。
- **現在の対策**: UI のエラーバナーにて分かりやすいメッセージを表示。
- **今後の改善案**: 初回起動時に API キーの入力を促す初期セットアップガイドダイアログの追加。

## 5. 今後の拡張アイデア

1. **命名規則のリアルタイムプレビュー**: 命名規則の編集モーダル上で、サンプルファイル名に対するプロンプト適用結果を即座にシミュレーション表示する機能。
2. **ドラッグ＆ドロップ対応**: エクスプローラーから動画フォルダを Renamer ウィンドウにドラッグ＆ドロップして即時走査を開始する機能。
3. **トレイ常駐監視モード**: バックグラウンドタスクとして動画フォルダを定期監視し、260文字超のファイルが追加された際にトースト通知する機能。
