# Spec Delta: video-library

## MODIFIED Requirements

### Requirement: HTTP Range Requests (HTTP 206) による動画ストリーミング配信

システムは、`GET /api/videos/{id}/stream` に対する Range リクエストヘッダーを解釈し、指定されたバイト範囲のストリーミングデータと HTTP 206 Partial Content レスポンスを返却しなければならない（SHALL）。対象動画の物理ファイルがストレージ上に存在しない場合は HTTP 404 Not Found を返却しなければならない（SHALL）。また、Linux (WSL / Docker / DevContainer) 環境等においてファイル名の長さがカーネル制限（`NAME_MAX` 255バイト）を超過している場合、システムはストリーミング実行前にファイル名単体の UTF-8 バイト数を検査して直ちに HTTP 422 Unprocessable Entity とエラーコード `FILE_NAME_TOO_LONG` を含む JSON レスポンスを返却しなければならない（SHALL）。ストリーミング実行中に `PathTooLongException` や関連する例外が発生した場合も HTTP 500 クラッシュを起こしてはならず（SHALL NOT）、安全に捕捉して同様に HTTP 422 JSON を返却しなければならない（SHALL）。なお、クライアント切断（`OperationCanceledException`）時はエラーログを記録せず安全にハンドラーを終了しなければならない（SHALL）。

#### Scenario: シーク再生時の部分コンテンツ要求

- **WHEN** クライアントから Range ヘッダーを含む動画ストリーム要求が送信されたとき
- **THEN** サーバーは HTTP 206 と共に Content-Range ヘッダーおよび要求範囲の動画バイナリを返却すること

#### Scenario: 実ファイル消失時の 404 エラー応答

- **WHEN** DBに登録されているが物理ストレージ上に実ファイルが存在しない動画のストリームが要求されたとき
- **THEN** サーバーは HTTP 404 Not Found を返却し、クライアントに動画が存在しないことを通知すること

#### Scenario: Linuxファイル名長制限超過時のFail-Fast HTTP 422と専用エラーコード返却

- **WHEN** ファイル名が Linux の 255 バイト制限を超過している動画に対してストリーミング配信が要求された時
- **THEN** サーバーは 500 エラーにならず、HTTP 422 と `{"code": "FILE_NAME_TOO_LONG", "error": "ファイル名が Linux の 255 バイト制限 (NAME_MAX) を超過しているため再生できません。"}` を返却する

#### Scenario: クライアント切断時の正常終了

- **WHEN** 動画再生中にクライアントが接続を切断（タブ閉じ・シーク）してキャンセルされた時
- **THEN** サーバーは未処理例外として 500 エラーログを記録することなく静かに処理を完了すること

## ADDED Requirements

### Requirement: ストリーミングエラー時のフロントエンド詳細通知とオーバーレイ表示

フロントエンド（Web UI）は、動画プレイヤー（`<video>`）におけるストリーミング再生エラー（`@error`）を検知した際、ストリーミングエンドポイントへ非同期リクエストを発行してステータスコードおよびエラーレスポンスを解析しなければならない（SHALL）。ファイル名長制限（`FILE_NAME_TOO_LONG`）を検知した場合は、赤色トースト通知を表示するとともに、プレイヤー画面領域の中央にエラーオーバーレイを表示し、ファイル名が Linux の 255 バイト制限を超過している旨、該当ファイルのパス、および「ファイルパスをコピー」ボタンを表示して AI File Renamer 等での短縮リネームを案内しなければならない（SHALL）。

#### Scenario: FILE_NAME_TOO_LONG発生時のトースト通知とプレイヤーオーバーレイ表示

- **WHEN** ユーザーが動画一覧から Linux 255バイト制限超過の動画をクリックして再生を開始し、ストリーミングが HTTP 422 で失敗した時
- **THEN** 画面上に「⚠️ 再生エラー: ファイル名が Linux の 255 バイト制限を超過しています」の赤色トースト通知が表示され、プレイヤー中央に「再生できません / ファイルパスをコピー」を含むオーバーレイメッセージが表示される

#### Scenario: 通常のエラー発生時のトースト通知

- **WHEN** ネットワーク切断やファイル不在等で通常のストリーミングエラーが発生した時
- **THEN** 画面上に適切なエラー内容のトースト通知が表示される
